# ⚖️ Direito Claro

### Tecnologia, acessibilidade e impacto social

## 📌 Sobre o projeto

O **Direito Claro** é um projeto acadêmico desenvolvido em grupo na disciplina de Tecnologia e Impacto Social.

A proposta é facilitar o acesso a informações sobre direitos de pessoas autistas e suas famílias, utilizando uma linguagem mais clara, acessível e organizada.

## 🎯 Objetivo

Desenvolver uma plataforma informativa que ajude os usuários a compreender temas relacionados a direitos e inclusão, reduzindo barreiras de acesso à informação.

## 📚 Temas abordados

- Benefício de Prestação Continuada (BPC/LOAS).
- Direitos relacionados à educação inclusiva.
- Planos de saúde e acesso a terapias.
- Aposentadoria da pessoa com deficiência.
- Orientações gerais e conteúdos explicativos.

## 🛠️ Desenvolvimento

O projeto envolve atividades de pesquisa, organização de conteúdo, documentação e prototipação de interfaces.

**Ferramentas e tecnologias:**
- HTML e CSS — prototipação da interface.
- Documentação e pesquisa acadêmica.

## 👥 Trabalho em equipe

Projeto desenvolvido coletivamente, envolvendo pesquisa, planejamento, elaboração do protótipo e organização dos materiais.

## ⚠️ Aviso importante

Este é um projeto acadêmico de caráter informativo e educacional.

O conteúdo não substitui orientação jurídica profissional e não deve ser interpretado como serviço de consultoria jurídica. A validação jurídica dos textos não está confirmada.

## 📌 Status

Protótipo acadêmico desenvolvido para apresentação e avaliação na disciplina de Tecnologia e Impacto Social.
